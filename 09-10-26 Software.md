## Categories of software
- Software can be grouped into several categorises
	- system software
		- Operating system
		- utility program
		- Library programs
		- Translators
	- application software
		- On the shelf
		- open source
		- propriety 
		- custom written
#### System software
- Needed the system to control hardware and run applications
	- utilities 
	- libraries
	- translators

### Utility programs
- Disk defragmenter
	- Larger files are stored on a magnetic hard drive may be split up across several physical disk locations
	- Disk defragmentation recognises the hard drive so files are in **sequential blocks** where possible
	- The results is that **files can be read more quickly** 
- Automatic backup
	- Data in permanent storage needs to be backed up
	- IF the data hasn't been edited since last backup, it does **NOT** need to be backed up again as a backup of the file already exists
- Automatic updating
	 - Runs in the background detecting **software updates** releases and automatic lay installs then 
- Virus checking
	- Scans permanent storage for **viruses** by comparing files to knows virus definitions
		- May also scan files *'on access'* as they are opened 
		- Must be kept up to date with new virus definitions, to be effective
- Compression software
	- WE may want to send large files across the internet
	- Compression software can **reduce the size of files**

## Open source software
- Open source software allows anyone to access the source code
- The software is open source **licenced** but free to use 
- Anyone may **modify the software** and sell it, on the condition that the software produced is also open source
- Open source software is usually free

## Closed source/propiatery 
- Does not allow access to the source code
- User may pay the copyright owner if they want a licence to use the software
- There may be restrictions on how the software is used
	- e.g. it may only be licenced to be used by one person, on one machine, or on a physical site
