# Thinking Abstractly

## Lesson Overview

> [!IMPORTANT] Lesson Objectives
> - Understand the nature of and need for abstraction.
> - Describe the differences between an abstraction and reality.
> - Devise an abstract model for a variety of situations.

## What Is Computational Thinking?

> [!NOTE]
> Computational thinking is the ability to think logically about a problem and apply techniques for solving it.

Computational thinking is closely related to designing algorithms that can be turned into computer programs.

### Key Questions

- What information is relevant to solving a particular problem?
- What computations need to be performed?
- How can we determine whether the problem has been solved?

## Computer Science and Abstraction

Computer Science:

- Uses mathematical principles to solve problems.
- Is not simply learning to use software applications.
- Requires computational thinking.
- Relies heavily on [[Abstraction]].

## What Is Abstraction?

> [!NOTE] Definition
> Abstraction is a method of separating the logical aspects of a problem from the physical details.

### Driving Example

| Learner | Main Focus |
|----------|------------|
| Driver | Steering, accelerator, brakes and controls |
| Mechanic | How the components actually work |

An abstraction focuses only on the details needed for the current task.

## Thinking Abstractly

Abstraction typically involves:

1. Creating a model that represents reality.
2. Removing unnecessary details.
3. Keeping only information relevant to the problem.

### Queue Example

When deciding how many tills a new store needs, details such as customers' favourite colours are irrelevant.

Relevant details might include:

- Number of customers.
- Arrival rates.
- Service times.
- Queue lengths.

## Abstraction and Reality

> [!IMPORTANT]
> All details that do not contribute to solving the problem are omitted.

### Example: London Underground Map

The London Underground map is an abstraction because it hides unnecessary geographic detail and focuses on routes, stations and connections.

## Problem Abstraction

Problem abstraction means reducing a problem until it resembles one that has already been solved.

### Examples

| Situation | Common Feature |
|-----------|----------------|
| Town map, country map, ocean-floor map | Represent real locations using simplified models |
| Fingerprint, iris, footprint, text and number plate recognition | Pattern recognition |

## Modelling and Simulation

A model of a real-world object or phenomenon can help solve problems.

The process is usually:

1. Identify relevant details.
2. Discard irrelevant information.
3. Design algorithms and data structures.
4. Implement the solution in code.
5. Execute and evaluate the model.

### Real-World Models

| Model | Purpose |
|--------|---------|
| Financial model | Predict likely profit from a business |
| Climate model | Predict consequences of temperature changes |
| Aircraft simulator | Train pilots safely |

## Lesson Summary

> [!IMPORTANT] Exam-Style Summary
> Abstraction is a fundamental principle of computational thinking.
>
> By removing irrelevant details, computer scientists can focus on the essential characteristics of a problem and design effective solutions.
