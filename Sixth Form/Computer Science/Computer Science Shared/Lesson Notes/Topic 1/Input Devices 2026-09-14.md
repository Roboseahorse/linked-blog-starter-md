## Lesson Objectives

- Describe different input devices.
- Explain how different input devices can be applied to solve different problems.

> [!IMPORTANT]
> An **input device** transfers data from the outside world into a computer system.

## Manual Input Devices

### Keyboards and Keypads

- Used to enter text, numbers and commands.
- Keypads are often used in specialist systems.

| Device | Typical Uses |
|----------|----------|
| Keyboard | Documents, programming, email |
| Numeric keypad | ATMs, security systems, tills |

### Pointing Devices

| Device | Description | Advantage |
|----------|----------|----------|
| Mouse | Controls pointer movement | Easy to use |
| Trackball | User rotates a ball while device stays still | Requires less desk space |

### Touchscreens

- Found in phones, tablets and smart watches.
- Allow direct interaction with on-screen objects.

### Interactive Whiteboards

- Display computer output to an audience.
- Can be used like a touchscreen.
- Allow annotations to be written over content.
- Notes and annotations can be saved.

## Automatic Input Devices

### Barcode Readers

> [!NOTE]
> Barcode readers convert a printed barcode into digital data.

| Barcode Type | Uses | Features |
|----------|----------|----------|
| UPC-A | Retail and warehousing | Numbers only |
| Code 128 | Transport and shipment tracking | Letters and numbers |

### QR Codes

- Two-dimensional barcodes.
- Read using phones and tablets.
- Can store website links and information.

Common uses:
- Concert tickets
- Advertising posters
- Business cards
- Tourist information
- Restaurant offers

### 2D Scanners

- Convert paper documents or photographs into digital files.
- Useful for archiving and sharing documents electronically.

### 3D Face Recognition

- Used in security systems.
- Measures facial features and compares them with stored records.

### 3D Scanners

- Used in industrial design and medicine.
- Often use **tomography**, which creates images from many thin slices.

## Sensors

> [!IMPORTANT] Sensor Definition
> A sensor is a hardware device that measures physical properties from the real world.

- Sensors usually produce **analogue data**.
- Analogue data often needs converting to digital using an **ADC (Analogue-to-Digital Converter)**.
- Sensors are used in both monitoring and control systems.

### Analogue Data

Analogue data:
- Has no fixed discrete values.
- Changes smoothly over time.

Examples:
- Thermometer
- Speedometer
- Seismometer

## Types of Sensors

| Sensor | Example Uses |
|----------|----------|
| Temperature | Heating systems, greenhouses |
| Moisture/Humidity | Soil monitoring, greenhouses |
| Light | Street lights, automatic headlights |
| Infra-red | Motion detection, burglar alarms |
| Pressure | Weigh bridges, weather monitoring |
| Acoustic | Noise monitoring, alarms |
| Gas | Pollution monitoring, exhaust testing |
| pH | Water quality, soil analysis |
| Magnetic Field | Smartphones, ABS systems |

## Monitoring and Control

### Monitoring Systems

> [!NOTE]
> Monitoring systems observe and report conditions but do not change the process.

Examples:
- Patient vital signs
- River pollution monitoring
- Burglar alarms

### Control Systems

> [!NOTE]
> Control systems automatically change the process based on sensor data.

Examples:
- Street lighting
- Air conditioning
- Traffic lights
- Anti-lock braking systems (ABS)

## Intruder Detection System Example

1. User activates the alarm using a PIN or key fob.
2. Sensors continually gather data.
3. Data is converted to digital form using an ADC.
4. A microprocessor compares readings with preset values.
5. If a threshold is exceeded, an alarm is triggered.
6. Monitoring continues until the system is deactivated.

### Sensors Used in Burglar Alarms

| Sensor | What It Detects |
|----------|----------|
| Pressure | Footsteps or weight |
| Acoustic | Breaking glass, sounds |
| Infra-red | Movement and heat changes |

## River Pollution Monitoring Example

1. Sensors measure oxygen and pH levels.
2. Readings are sent to a computer.
3. An ADC converts analogue data to digital data.
4. Values are compared with preset limits.
5. Operators receive warnings if limits are exceeded.
6. Monitoring continues continuously.

## Summary

- Input devices transfer data into a computer.
- Some require human interaction, others collect data automatically.
- Sensors often produce analogue data.
- ADCs convert analogue signals into digital signals.
- Monitoring reports information.
- Control systems make automatic changes.
