> How does machine code relate to assembly language programs?
> 
> > [!check] Answer
> Assembly language is translated using a compiler into machine code that the computer can understand.
> 
> **Key point:** In most cases, one assembly language instruction corresponds to one machine code instruction.
> 

The processor can only send signals to the address bus, it can send and receive signals on the data bus, and send and receive on the control bus. The Input and Output can send and receive signals from the address bus, data bus and control bus. The memory can receive signals from the address bus and send and receive signals from the data and control bus.
