BIOS (Basic Input/Output System) is **firmware** stored on a computer's motherboard that starts running when the computer is powered on. It **initialises and checks the hardware** using the Power-On Self-Test (POST), then begins the process of loading the [[Operating System (OS)]]. Modern computers commonly use **UEFI** as the successor to traditional BIOS. [https://en.wikipedia.org/wiki/BIOS](https://en.wikipedia.org/wiki/BIOS)
