Segmentation is a [memory management](https://www.geeksforgeeks.org/operating-systems/segmentation-in-operating-system/) technique where a program is divided into **variable-sized sections called segments**, based on logical parts such as code, data or functions. Each segment can be stored in a different location in memory and is accessed using a segment number and an offset.
