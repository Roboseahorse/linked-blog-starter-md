Paging is a [memory management](https://www.geeksforgeeks.org/operating-systems/paging-in-operating-system/) technique where memory is divided into fixed-size blocks called **pages**. Pages can be transferred between secondary storage and RAM as needed, allowing virtual memory to be used when there isn't enough RAM available.
