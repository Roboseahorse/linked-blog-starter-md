## What Is Abstraction?

> [!NOTE] Definition
> Abstraction is a method of separating the logical aspects of a problem from the physical details.

### Driving Example

| Learner  | Main Focus                                 |
| -------- | ------------------------------------------ |
| Driver   | Steering, accelerator, brakes and controls |
| Mechanic | How the components actually work           |

An abstraction focuses only on the details needed for the current task.

## Thinking Abstractly

Abstraction typically involves:

1. Creating a model that represents reality.
2. Removing unnecessary details.
3. Keeping only information relevant to the problem.

### Queue Example

When deciding how many tills a new store needs, details such as customers' favourite colours are irrelevant.

Relevant details might include:

- Number of customers.
- Arrival rates.
- Service times.
- Queue lengths.

## Abstraction and Reality

> [!IMPORTANT]
> All details that do not contribute to solving the problem are omitted.

### Example: London Underground Map

The London Underground map is an abstraction because it hides unnecessary geographic detail and focuses on routes, stations and connections.

## Problem Abstraction

Problem abstraction means reducing a problem until it resembles one that has already been solved.

### Examples

| Situation                                                       | Common Feature                                   |
| --------------------------------------------------------------- | ------------------------------------------------ |
| Town map, country map, ocean-floor map                          | Represent real locations using simplified models |
