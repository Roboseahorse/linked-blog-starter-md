## Distributed operating system
- We already know that the iterating system manages communication with the hardware
- A distributed OS can coordinate the processing of a single job across multiple computers
- A program can be run by the user that uses data or resources from any other computer
	- **Resources could include processor time, memory and I/O facilities**
- The distribution of tasks is coordinated by the OS passing instructions between computers
- The user can access more computational power with the illusion of working with a single processor

## [[Multi-tasking]] system
- A single processor can appear to be doing more than one task simultaneously by [[CPU Scheduling|Scheduling]] processor time
#### Mainframe
- Some systems use a very powerful computer called a mainframe 
	- These might be seen in large businesses 
- Lots of users with their own terminals access the mainframe CPU and each get a time slice
- each terminal is also running multiple processes

## Mobile operating system

- Mobile operating systems are linked to specific hardware
	- e.g. android phones have different hardware to IOS ones
- A low level proprietary OS is used for handling the hardware and special features
	- Features include cellular connectivity and wi-fi

## Open source operating system
- **Android** is an open source OS based on Linux and owned by google
- It is used by all major device manufacturers
- It allows for major customisation
- A device manufacturer can fine-tune the OS to suit their devices, and add additional features 
- user interfaces to enhance the user experience
- The interface and the available apps can be a major selling point
