## Pattern recognition
- Medical diagnostics
- Speed cameras
- Detecting a dangerously overcrowded platform on an underground railway

```
sweets=1
bags=0
while sweets<bags:
	bags=int(input(""))
	sweets=int(input(""))
	if sweets>bags:
		Solution = sweets MOD bags
		if Solution == 0:
			print ("YES")
		else:
			print("no")
	else:
		print("sweets must be greater than bags")
```
