## Ram
- When applications or programs are loaded they are copied into RAM from secondary storage (e.g. hard disk) 

### Virtual memory
- Once RAM is filled up applications that are sitting idle in RAM are moved into virtual storage

## Secondary storage devices
- Different technologies have evolved for saving data 
- Each of these have their own advantages ad disadvantages
